# 🛒 Olist Brazilian E-Commerce Advanced SQL Analytics Engine

An enterprise-grade relational database and advanced analytics project built using PostgreSQL. This project moves beyond basic queries to explore complex window functions, performance tuning, and customer behavior segmentation (RFM) on 9 relational tables.

## 📂 Repository Structure
- `schema/`: DDL scripts containing table architectures, Primary Keys, and Foreign Keys.
- `queries/`: Advanced analytical SQL queries (CTEs, Window Functions, Cohort Analysis).
- `optimization/`: Execution plan comparisons (`EXPLAIN ANALYZE`) and indexing strategies.

## 🛠️ Tech Stack
- **Database:** PostgreSQL
- **Management Tool:** pgAdmin 4
- **Version Control:** Git & GitHub
