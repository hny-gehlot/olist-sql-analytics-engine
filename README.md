# 🛒 Olist Brazilian E-Commerce | SQL Analytics Engine

An end-to-end SQL analytics project using **PostgreSQL, Python, SQLAlchemy, and Jupyter Notebooks** to explore real-world e-commerce data.

The project focuses on building a relational database, validating data quality, and developing SQL-based analytical solutions to understand customer behavior, sales performance, and business trends.

## 🎯 Project Objectives

- Design and manage a relational database using primary and foreign keys.
- Validate data quality and explore relationships across multiple tables.
- Analyze customer behavior, orders, revenue, and product performance.
- Develop advanced SQL queries using joins, CTEs, and window functions.
- Explore customer segmentation using RFM analysis.
- Investigate query optimization through indexing and execution plans.

## 📂 Repository Structure

- `data/` — Raw Olist CSV files (excluded from Git).
- `schema/` — SQL scripts defining tables, constraints, and relationships.
- `notebooks/` — Database connectivity, data validation, and exploratory analysis.
- `queries/` — SQL queries for business analysis.
- `optimization/` — Query performance analysis and optimization experiments.

## 🛠️ Tech Stack

- **Database:** PostgreSQL
- **Programming:** Python
- **Libraries:** Pandas, SQLAlchemy, psycopg2
- **Environment:** Jupyter Notebook, VS Code
- **Version Control:** Git & GitHub

## 📊 Dataset

**Brazilian E-Commerce Public Dataset by Olist**

Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

The dataset contains information about customer orders, products, sellers, payments, reviews, and delivery activity from a Brazilian e-commerce marketplace.
